# Age of War 中文说明

这是经典 Flash 游戏《Age of War》的 Godot 复刻版本。

## 内置多语言系统

游戏使用运行时多语言系统，不是 Godot 编辑器插件，也不需要安装额外插件。

语言管理器通过项目 Autoload 加载，翻译资源位于：

```text
localization/translations.csv
```

### CSV 格式

第一行定义语言列，格式为：

```csv
keys,en__English,zh_CN__简体中文
```

- `keys`：原始文本键，通常使用游戏中的英文文本。
- `en`、`zh_CN`：语言代码。
- `English`、`简体中文`：设置界面显示的语言名称。
- `__`：语言代码与显示名称之间的分隔符。

每个后续行包含一个原始文本和各语言翻译。空翻译会回退到原始文本。

### 新增语言

只需在 CSV 中增加一列，并填写语言代码和显示名称，例如：

```csv
keys,en__English,zh_CN__简体中文,ja__日本語
```

然后在对应列中填写翻译。运行游戏后，进入 `Options > Language` 即可选择新语言，无需修改 GDScript，也无需安装 Godot 插件。

### 注意事项

- 语言代码建议使用标准格式，例如 `en`、`zh_CN`、`ja`。
- 语言列名称不要使用 `:`，请使用 `__` 分隔代码和显示名称。
- 多行文本需要放在 CSV 的双引号字段中。
- 修改 CSV 后重新加载项目或重新运行游戏，使 Godot 重新导入资源。
